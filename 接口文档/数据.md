### <a id="SyncToClientModRenderAttrByKey"></a>SyncToClientModRenderAttrByKey

- 描述<br>
  手动同步缓存数据至客户端，以防客户端GetModRenderAttrByKey获取为空

- 服务端参数

|参数名|数据类型|说明|

        |PlayerId|str|玩家id，默认为None则同步所有玩家|

- 客户端参数

|参数名|数据类型|说明|
        |:-:|:-:|:-:|
        |PlayerId|str|玩家id，默认为None则同步所有玩家|

- 返回值<br>
  无

- 备注<br>
无

- 示例
空

### <a id="setmodrenderattrbykey"></a>SetModRenderAttrByKey
<font color=orange>双端</font><br>
- 描述<br>
  设置存储于实体数据新的值(仅限于本存档)

- 服务端参数

|参数名|数据类型|说明|
|:-:|:-:|:-:|
|EntityId|str|实体id|
|DataKey|str|数据Key|
|Value|dict|数据值|
|OnlyServer|bool|是否仅在服务端存储，默认为False，即同步至客户端|

- 客户端参数

|参数名|数据类型|说明|
|:-:|:-:|:-:|
|EntityId|str|实体id|
|DataKey|str|数据Key|
|Value|dict|数据值|

- 返回值<br>
  无

- 备注<br>
  - 当EntityId为自定义str时，存档效果将失效。
  - 客户端使用该接口时，仅客户端缓存数据，不存档！

- 示例
空
------------

### <a id="getmodrenderattrbykey"></a>GetModRenderAttrByKey
<font color=orange>双端</font><br>
- 描述<br>
  获取存储于实体数据的值

- 服务端参数

|参数名|数据类型|说明|
|:-:|:-:|:-:|
|EntityId|str|实体id|
|DataKey|str|数据Key|
|OnlyServer|bool|用于获取仅服务端缓存的数据，默认为False|

- 客户端参数

|参数名|数据类型|说明|
|:-:|:-:|:-:|
|EntityId|str|实体id|
|DataKey|str|数据Key|
|OnlyClient|bool|用于获取仅客户端缓存的数据，默认为False|

- 返回值<br>
  - SetModRenderAttrByKey存储的数据(dict)
  - UseServerApi开启OnlyClient返回的数据(any)

- 备注<br>
  无

- 示例
空
------------

### <a id="localconfigdata"></a>LocalConfigData
<font color=blue>客户端</font><br>
- 描述<br>
  存储或获取本地存储数据

- 参数

|参数名|数据类型|说明|
|:-:|:-:|:-:|
|Key|str|数据的名称，用于区别不同的本地数据|
|Dict|dict|数据内容，默认为None则为获取并返回该Key的数据，反之不为None则是存储数据|
|IsGlobal|bool|为True时是全局配置，否则为存档配置，默认为False|

- 返回值<br>
  存储或获取本地存储数据 (dict)

- 备注<br>
  无

- 示例
空
------------

### <a id="getmodconfigvalue"></a>GetModConfigValue
<font color=blue>客户端</font><br>
- 描述<br>
  获取模组设置的值

- 参数

|参数名|数据类型|说明|
|:-:|:-:|:-:|
|ModName|str|指config.ModName|
|Key|str|对应设置配置数据中的[Key](/docs/ability#registermodsettingconfig)，默认为None，则获取该模组所有的设置值|

- 返回值<br>
  模组设置的值，没有则返回None (bool, float, int, str)

- 备注<br>
  无
